📚 Gérer mes ebooks

Ajoute, modifie ou supprime tes ebooks. Cette page n'envoie rien sur internet : tout reste dans ton téléphone.

1Mes ebooks

Voici les ebooks de ton site. Touche « Modifier » pour changer un ebook.

    2Ajouter un ebook

    Les cases avec * sont obligatoires.

    Mets d'abord ta photo dans le dossier « images » sur GitHub, puis écris son nom ici. Une photo remplace le dessin et l'icône.

    Laisse vide si l'ebook n'est pas encore sur Chariow : le bouton restera caché.

    3Mettre à jour le site

    Quand ta liste est prête, copie le texte ci-dessous et colle-le dans le fichier ebooks.json sur GitHub.

    ✏️ Ouvrir ebooks.json sur GitHub
    1. Touche « Copier le texte ».
    2. Touche « Ouvrir ebooks.json sur GitHub » et connecte-toi si besoin.
    3. Dans le fichier, efface tout (appui long → Tout sélectionner → Effacer).
    4. Colle le texte copié.
    5. Touche « Commit changes », puis encore « Commit changes ».
    6. Attends 1 à 2 minutes, puis recharge ton site : le nouvel ebook apparaît ✅
