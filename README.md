# Ma Boutique Digitale

Un petit site pour vendre mes e-books.

## Les fichiers

- `index.html` : la page d'accueil, avec le texte et la liste des e-books.
- `style.css` : l'apparence du site (couleurs, tailles, mise en page).
- `README.md` : ce fichier, qui présente le projet.

## Comment ajouter un e-book

1. Ouvre `index.html`.
2. Copie un bloc `<article class="ebook"> ... </article>`.
3. Colle-le juste en dessous, puis change le titre, la description et le prix.
4. Remplace le `#` du bouton « Acheter » par ton lien de paiement.

## Pour encaisser les paiements

Ce site affiche tes e-books, mais il ne gère pas l'argent lui-même.
Pour cela, il faut une plateforme de vente d'e-books, qui encaisse le paiement
et envoie le fichier au client. Elle te donne un lien de paiement pour chaque e-book :
c'est ce lien que tu mets dans le bouton « Acheter ».
